# AViator Predictor

Аналитический интерфейс по историческим раундам: React + TypeScript + Tailwind + Recharts.
Проект ничего не предсказывает: он показывает описательную статистику и честно маркирует демо-данные.

## Запуск

```bash
npm install
npm run dev      # разработка
npm run build    # проверка типов + сборка в dist/
```

## Деплой на Vercel

Vercel сам определит Vite. Build command: `npm run build`, output: `dist`.

## Реальный источник данных

По умолчанию работает демо-режим (синтетические данные с пометкой «ДЕМО»).
Чтобы подключить легальный источник истории, задайте переменную окружения в Vercel:

```
VITE_HISTORY_API_URL=https://your-source.example/history
```

Ожидаемый ответ: `[{ "id": 12345, "multiplier": 2.31, "ts": 1760000000000 }, ...]`
(или объект `{ "rounds": [...] }`). Некорректные записи отбрасываются и считаются.
Переменная попадает в браузер, поэтому ключи доступа в неё класть нельзя.
Если источнику нужен секрет, поставьте перед ним собственный серверный прокси.
Затем отключите «Демонстрационные данные» в настройках.
